# ElectriQuote v1

Webes villanyszerelési árajánlat-készítő Netlify Functions és Netlify Blobs alapú közös előzményekkel.

## Futtatás

Az oldal statikus `index.html` fájlból és a `netlify/functions/quotes.mjs` háttérfunkcióból áll. Netlify deployhoz a `netlify.toml` konfiguráció használható.

Az ajánlatelőzmények közösek: minden látogató ugyanazt a mentett listát látja.
